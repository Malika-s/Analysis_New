lesson review

Catch what's wrong, outdated, or missing in a single lesson.

Give it a transcript — pasted in, from an .srt/.vtt caption file, transcribed live from an .mp4, or pulled out of a zipped/tarred lesson folder — and Claude reads through it looking for factual mistakes, outdated information, gaps in coverage, and confusing explanations, timestamped wherever possible.

1 — Give it something to read

CAPTION FILE

.srt or .vtt file

Timestamps are kept, so flagged issues can point back to a moment in the video.

Live transcription only works in Chrome or Edge, needs the video to play in real time, and its accuracy varies. If it doesn't pick anything up, use the .srt or paste-transcript tab instead.
VIDEO FILE

.mp4 file

Plays silently in the background while your browser transcribes it live.

ARCHIVE FILE

.zip or .tar file

Drop a zipped or tarred lesson folder — the app looks inside for an .srt/.vtt caption file or an .mp4 video and loads whichever it finds automatically.
